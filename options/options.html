Where the key is stored

The key is saved in this Chrome profile's extension storage on this computer only, and it persists across browser restarts. It is sent only to googleapis.com, and only by the extension's background service worker. It is never written into a YouTube page, never logged, and never included in an error message.

Extension storage is restricted to trusted contexts (setAccessLevel: TRUSTED_CONTEXTS), so the content script running inside youtube.com cannot read it either.

Each computer is configured separately. Using a different API key on each machine is recommended for independent revocation and management. API keys in the same Google Cloud project share that project's YouTube Data API quota.

Methodology

The calculation method is fixed so that everyone at Ternary House produces the same number. It is not configurable here.
